### 📜 Wild camping rules — Scottish Outdoor Access Code

- **Légal partout** sauf zones bylaws Loch Lomond (zone est interdite avril-octobre dans certains périmètres). **Vérifier carte officielle** : [lochlomond-trossachs.org/things-to-do/camping](https://www.lochlomond-trossachs.org/things-to-do/camping/). On évite ces zones (notre route passe ouest Loch Lomond ou Stirling direct).
- **Règles pratiques** :
  - 4-5 m du chemin
  - Hors vue des fermes/maisons
  - 4 m d'un cours d'eau (sauf plage)
  - Groupes de 6+ : envisager plusieurs sites espacés (notre groupe = 7 = limite, OK)
- **Feux** : INTERDITS en zones tourbeuses (peat, mousse) — risque incendie. **Réchaud uniquement** dans la majorité des spots. **Sandwood Bay sable + bois flotté** = exception possible avec prudence.
- **Toilettes** : règle "cathole" (15-20 cm, 50 m d'un cours d'eau). **Wagbag pour zones très fragiles** (Sandwood, Quiraing). Apporter sacs déchets pour ramener absolument tout.
- **Bothies (Mountain Bothies Association)** : ~100 abris gratuits non-réservables FCFS. Pas inclus dans plan principal mais option si météo cataclysmique. [mountainbothies.org.uk/bothies/bothy-locations](https://www.mountainbothies.org.uk/bothies/bothy-locations/).

**🐜 MIDGES + MÉTÉO — préparation non négociable**

Fin juillet-début août = **PIC absolu de midges** (Culicoides impunctatus) en Highlands. Sans préparation, le voyage devient cauchemardesque. **Avec préparation, c'est gérable** — surtout dans les spots venteux qu'on a choisis (côte Skye, Sandwood Bay, Glen Etive en mouvement).
