### 🍺 Pub crawl historique itinéraire (J2 soir, à l'arrivée)

**Boucle Old Town classique, ~6 pubs, 3-4 h, distance 2 km** :

1. **The Devil's Advocate** (8 Advocate's Close, Old Town) — pub élégant dans une vieille pump house, 200+ whiskies écossais. Démarrage chic. **Pint £6**.
2. **The Last Drop** (74 Grassmarket) — pub historique au-dessus de l'ancien lieu d'exécution publique. Ambiance pub écossais classique, food OK. **Pint £5,50**.
3. **The Bow Bar** (80 West Bow) — pub authentique 30 whiskies single malt + 8 ales locales. Pas de musique, conversation pub. **Pint £5,50**.
4. **The Jolly Judge** (7A James Court) — pub caché dans une close du Royal Mile, plafond bas + cheminée. Atmosphère médiévale. **Pint £5,50**.
5. **Greyfriars Bobby's Bar** (Candlemaker Row) — pub à côté du célèbre Greyfriars Bobby (statue du chien). Touristique mais culte. **Pint £6**.
6. **Sandy Bell's** (25 Forrest Road) — **THE folk music pub of Edinburgh** depuis 1940. Live folk session quasi tous les soirs (gratuit). **Finale parfaite**. **Pint £5,50**.

**Coût estimé** : ~£35/pax pour 6 pints + snacks = $60/pax × 7 = $420 groupe.

### 📜 Wild camping rules — Scottish Outdoor Access Code

- **Légal partout** sauf zones bylaws Loch Lomond (zone est interdite avril-octobre dans certains périmètres). **Vérifier carte officielle** : [lochlomond-trossachs.org/things-to-do/camping](https://www.lochlomond-trossachs.org/things-to-do/camping/). On évite ces zones (notre route passe ouest Loch Lomond ou Stirling direct).
- **Règles pratiques** :
  - 4-5 m du chemin
  - Hors vue des fermes/maisons
  - 4 m d'un cours d'eau (sauf plage)
  - Groupes de 6+ : envisager plusieurs sites espacés (notre groupe = 7 = limite, OK)
- **Feux** : INTERDITS en zones tourbeuses (peat, mousse) — risque incendie. **Réchaud uniquement** dans la majorité des spots. **Sandwood Bay sable + bois flotté** = exception possible avec prudence.
- **Toilettes** : règle "cathole" (15-20 cm, 50 m d'un cours d'eau). **Wagbag pour zones très fragiles** (Sandwood, Quiraing). Apporter sacs déchets pour ramener absolument tout.
- **Bothies (Mountain Bothies Association)** : ~100 abris gratuits non-réservables FCFS. Pas inclus dans plan principal mais option si météo cataclysmique. [mountainbothies.org.uk/bothies/bothy-locations](https://www.mountainbothies.org.uk/bothies/bothy-locations/).

**🐜 MIDGES + MÉTÉO — préparation non négociable**

Fin juillet-début août = **PIC absolu de midges** (Culicoides impunctatus) en Highlands. Sans préparation, le voyage devient cauchemardesque. **Avec préparation, c'est gérable** — surtout dans les spots venteux qu'on a choisis (côte Skye, Sandwood Bay, Glen Etive en mouvement).

### Kit anti-midges obligatoire (acheter dès Edinburgh J2 — fenêtre idéale)

1. **Smidge Insect Repellent** (£8/100 ml) — **le SEUL produit qui marche** vraiment, picaridin (Saltidin). **3 bouteilles minimum** pour le groupe (1 par 2-3 personnes).
2. **Avon Skin So Soft Original** (£6/250 ml) — alternative populaire.
3. **Head nets** (£5/pax) — **7 obligatoires**. Décathlon ou Cotswold Outdoor Edinburgh.
4. **Manches longues + pantalons** pour le crépuscule (peak biting 18h-22h).
5. **Vent = sauveur** : > 7 mph wind = midges absents. **Nos spots wild camping sont presque tous venteux** (côte Skye, Sandwood Bay, Glen Etive en mouvement) — bonne couverture naturelle.
